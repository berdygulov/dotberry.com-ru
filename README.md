# SEO-продвижение dotberry.com

Анонимный доменный регистратор без KYC с оплатой криптовалютой (EN + RU).

## Структура папки
- `OVERVIEW.md` — общая информация о проекте: сервис, модель WHOIS/ToS, цены, ключевые выводы
- `TECH-SEO-AUDIT.md` — предварительный технический SEO-анализ с доказательствами
- `PLAN.md` — общий SEO-план с этапами и статусами
- `PLAN-SHORT.md` — краткий план: только общие направления и сроки
- `audit/` — аудиты (`YYYY-MM-DD-*.md`), `audit/raw/` — снапшоты robots.txt, sitemap.xml и пр.
- `tasks/` — отдельные задачи с деталями (`NNN-short-name.md`)
- `semantics/` — семантическое ядро (создаётся по мере работы)
- `content/` — ТЗ и тексты
- `reports/` — ежемесячные отчёты
